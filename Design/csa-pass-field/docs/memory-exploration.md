# 内存 Pass 探索副本

沿用 React Flow 和 AIC/AIV 计算流程，不增加 Cube/Vector。内存单元借鉴共享 pattern 的相对位置：L1 在左，L0A/L0B 居中上下，L0C 在右，UB 位于 AIV 计算附近。

IR Mat/Left/Right/Acc/Vec 分别对应 L1/L0A/L0B/L0C/UB。所有分配都在存储单元内部呈现。P33–35 内部块表示身份；P36 按地址和大小定位，空隙保留。图形尺度按各空间当前分配地址范围归一化，不代表硬件容量或同时存活量。

选中计算值或分配，双向高亮已有语义映射，显示相关区间并按需打开详情。主图计算仍是提炼图，变量归属通过 memoryOwner 显式规则映射；未建立映射的分配可查看完整绑定值，不虚构计算边。

验证：npm run build；node scripts/memory.test.mjs；浏览器 P33/P35/P36 与选择详情。

基础网格每个存储单元只绘制一次，12px 固定步长、9px 正方形，不随 Pass 或分配数量变化。分配作为透明交互覆盖层；只有选中或联动时覆盖蓝色。格子不承担容量、bank 或存活含义。
